# Curso: Lógica de Programação - Funções e Listas com JavaScript 📚✨

Este repositório contém os códigos desenvolvidos durante o curso [**"Lógica de Programação: funções e listas com JavaScript"**](https://cursos.alura.com.br/course/logica-programacao-funcoes-listas), oferecido pela [Alura](https://www.alura.com.br) como parte da formação **Oracle Next Education (ONE)**.

---

## 🧠 O que foi aprendido

Neste curso, aprofundamos conceitos essenciais de lógica e estruturação de código em JavaScript, com foco em:

- Declaração e chamada de funções
- Uso de parâmetros e retorno de valores
- Escopo de variáveis
- Funções anônimas e arrow functions (`=>`)
- Criação e manipulação de listas (arrays)
- Métodos como `push()`, `pop()`, `length`, `forEach()`
- Uso de loops `for`, `for...of` e `while` para percorrer listas

---

## 💻 Projeto desenvolvido

Ao longo do curso, foram criadas pequenas funções e exemplos práticos para fixar os conceitos, como:

- Funções que realizam cálculos (média, dobro, IMC, fatorial)
- Funções que manipulam listas de nomes e números
- Exibição dinâmica de resultados no console ou com `alert()`
